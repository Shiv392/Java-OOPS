## 🧠 What is OOP in Java?

Object-Oriented Programming (OOP) is a programming style where code is organized around objects.
An object is a real-world entity with:
- state (data/attributes), and
- behavior (methods/functions).

Example:
- Car → state: color, speed, model
- Car → behavior: start(), stop(), accelerate()

Java is an object-oriented language, so OOP is one of its core strengths.

---

## 💡 Why OOP exists

OOP was created to solve major software development problems:
- code became messy in procedural programming,
- reusability was poor,
- updating one part of the system was risky,
- large applications were hard to manage.

OOP makes software:
- easier to understand,
- easier to extend,
- easier to debug,
- safer to maintain.

---

## 🧩 What problems does OOP solve?

OOP helps with real-world software challenges such as:
- modeling real-life entities,
- reducing code duplication,
- improving team collaboration,
- securing data using access control,
- building scalable applications.

In short, OOP helps you write software that is structured, modular, and professional.

## 🏛️ The 4 pillars of OOP

### 1. Abstraction 🧩
Hide unnecessary details and show only what matters.

Example idea:
A driver only needs to know how to start a car, not how the engine works internally.

### 2. Encapsulation 🔒
Wrap data and methods together and restrict direct access.

Example idea:
A bank account should not allow direct changes to balance without rules.

### 3. Inheritance 🧬
Create new classes from existing ones to reuse code.

Example idea:
Dog and Cat can inherit from Animal.

### 4. Polymorphism 🌈
One interface, many forms.

Example idea:
A single method name can behave differently in different classes.
