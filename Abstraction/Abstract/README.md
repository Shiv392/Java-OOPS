## How to define abstraction using abstract keyword.
using abstract keyword, we can define abstract class and method.
=> abstract class shows what my class should do not how to do.

1. we can define an class using abstract keyword.
2. abstract can have abstract method that have no body
3. we can also define regular method with body inside this class, 
this method are called Concrete methods 
4. While inherting we can override the abstract methods to perform action.

Code Flow 
1. created an abstract class Vehicle with abstract method and regular method
2. Created a abstract class Vehicle with methods and properties.
3. Now created two Class Car & Bike with extending Vehicle 
4. By using MainClass, we can create object for Car & Bike, then call their methods.
