# Inheritance 🧬

Use this folder to learn how one class can reuse and extend another class.

## What to practice
- extends keyword
- parent and child classes
- method overriding
- real-world examples like Animal → Dog/Cat, Vehicle → Car/Bike

## Goal
Understand how inheritance reduces duplication and improves structure.

#Code Flow 
1. created an parent class Vehicle
2. now created an child class Car extending Vehicle class
3. Now Car class can access all methods of Vehicle class also it can override using @Override.
4. to access properties of parent class, we can use super keyword.
